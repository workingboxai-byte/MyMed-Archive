# Медкарта — Динаміка МРТ хребта (SOR 2025–2026)

Вебзастосунок для ведення персонального медичного архіву та візуального порівняння динаміки МРТ усіх відділів хребта (`SOR 2025` vs `SOR 2026`). Інтерфейс підтримує українську (основна), російську та англійську мови, світлу й темну теми, а також режим приватності для швидкого приховування персональних даних на екрані.

## Основні розділи

- **Анамнез і профіль** — базові біометричні дані з розрахунком ІМТ та 4-зонна карта скарг із прив'язкою до сегментів хребта.
- **Динаміка МРТ (SOR 2025–2026)** — інтерактивна 16-сегментна SVG-схема хребта (`C2–C3` — `L5–S1`), перемикач режимів `2025 / 2026 / Порівняння`, кількісні графіки змін, системні знахідки та зведена таблиця динаміки.
- **Обстеження і виписки** — хронологічний реєстр обстежень із пошуком, фільтрацією за категоріями та редагуванням записів.
- **Архів посилань** — зберігання посилань на знімки, скриншоти та DICOM-архіви (Lightshot, GitHub тощо) з прив'язкою до сегментів або записів.
- **Режим для лікаря** — структурована клінічна виписка формату A4 для друку або збереження у PDF.

## Приватність і дані

- У вихідному коді репозиторію не зберігаються особисті дані (ПІБ пацієнта, місто, дані лікаря).
- Усі зміни, додані записи, посилання та імпортований локальний JSON-архів зберігаються виключно локально в `localStorage` браузера користувача.
- У верхній панелі доступна кнопка «Режим приватності» для швидкого приховування ПІБ та міста під час перегляду екрана.

## Локальний запуск

```bash
npm install
npm run dev
```

Збірка для продакшену:

```bash
npm run build
```

## Деплой на GitHub Pages

Репозиторій містить workflow `.github/workflows/deploy.yml`, який автоматично збирає директорію `dist` і публікує її на GitHub Pages при пуші в гілку `main`. У налаштуваннях репозиторію (`Settings → Pages`) достатньо вибрати джерело публікації **GitHub Actions**.
